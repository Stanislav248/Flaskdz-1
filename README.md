# Візитка

Міні-сайт «Візитка» на Flask.

## Маршрути

| URL | Опис |
|-----|------|
| `/` | Головна сторінка зі списком проєктів |
| `/about` | Про мене |
| `/skills` | Навички |
| `/project/<id>` | Один із проєктів; для неіснуючого id — «Проєкт не знайдено» (404) |
| `/api/me` | Мої дані у форматі JSON |
